How I work

Three habits that show up in every system I ship.

01

Start with the business problem

Understand the workflow, the users and the data before reaching for a Microsoft feature or writing a line of code.

02

Use the right level of code

Stay low-code while the system stays maintainable. Bring in C#, custom APIs or Azure the moment complexity asks for it.

03

Build for production, not the demo

Security, environments, ALM and integrations are part of the build from day one — not something bolted on after launch.
